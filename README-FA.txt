فروشگاه HTML

فروشگاه ساده بازی‌های HTML با فهرست database/games.json.
برای انتشار سایت: Settings > Pages > Deploy from a branch > main > /(root) را انتخاب کن.
برای افزودن بازی، فایل HTML بازی را در پوشه games قرار بده و رکورد آن را به games.json اضافه کن.
نسخه فعلی دانلود آفلاین بازی‌های تک‌فایلی را پشتیبانی می‌کند. فایل‌های جانبی (عکس/صدا/مدل جدا) هنوز پشتیبانی کامل ندارند.

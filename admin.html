مدیریت فروشگاه HTML

برای انتشار بازی فعلاً از بخش فایل‌های مخزن GitHub استفاده کن:

  1. فایل بازی را در مسیر games/نام-بازی/index.html بارگذاری کن.
  2. فایل database/games.json را ویرایش کن و مشخصات بازی را به آرایه games اضافه کن.
  3. پس از چند لحظه بازی در فروشگاه نمایش داده می‌شود.

نمونه رکورد:

{"id":"game1","title":"نام بازی","description":"توضیح بازی","path":"games/game1/index.html"}
